# Parametric DIN-rail system

Native OCAF feature types generated by OCCT, edited through the shared modeling command, the `cad_din` agent tool and
the Create menu ("DIN Rail...", "DIN Module Bottom..."). See the agent card
[din-rail-system.md](agent-training-cards/din-rail-system.md) for parameters and examples.

| Feature | Parameters | What it is |
|---|---|---|
| `din_rail` | `lengthMm` 10-6000 | TS35 x 7.5 top-hat rail, axis on y = 0, flange plane z = 0 |
| `din_bottom` | `lengthMm` 28-1000, `widthMm` 60-1000, `thicknessMm` 3-30, `tabs` | The actual bottom of a module, with a fixed clip pocket |
| `din_clip` | none | Replaceable foot: fixed hook, spring-clip arm, release lug, friction-screw block |
| `din_screw` | `advanceMm` 0-0.9 | Nylon friction screw (modelled at thread minor diameter 2.4 mm) |

`cad_din` `module` creates a bottom, clip and screw together in one undoable step; `updateModule` changes one module
and leaves every other module untouched.

## Common reference

Module frame: origin at the alignment corner, +X along the rail, +Y across it, +Z up from the rail-contact plane. The
alignment edge is `y = 0`; the rail axis is 31 mm in front of it, so a module sits at `y = railY - 31`. The clip pocket
(x 2-26, y 8-58), hook, spring clip and screw block have fixed coordinates in this frame, so resizing a bottom never
changes the mounting geometry. Tabs (xmin, xmax, ymax edges only) are part of the bottom; the alignment edge stays
straight.

## Provenance and limits

- Documented (OBO Bettermann, WAGO TS35 x 7.5 data sheets, EN 60715): width 35 mm, height 7.5 mm, sheet 1.0 mm.
- **Provisional**: 27 mm outer wall spacing, vertical walls and the 4 mm flange width are not confirmed against the
  EN 60715 drawing; the standard's sloped walls are not modelled. Confirm before relying on lip clearances.
- The clip arm's strain and force figures are hand calculations for PETG (about 1.5 % strain, about 1.5 N to deflect),
  not simulation. The slit beside the arm is 2.0 mm so the arm can deflect 1.6 mm. Print and test.
- The hook and clip are one printable part (`din_clip`); the screw is a separate component and stays in the clip.
- Component publishing freezes geometry, so reuse is through the feature definitions (create the features in any
  document) or by saving a starter document.
